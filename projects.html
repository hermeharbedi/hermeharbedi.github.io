Count2Plan

Constrained Conditioned Floorplan Generation with Human-in-the-Loop Interaction

Ph.D. work, ongoing · Under review

Generative AIGANsDiffusionHuman-AI Co-Creation

Constraint-conditioned generative models for collaborative floorplan synthesis from high-level user specifications.

  • A slot-based conditional generator that dedicates each latent slot to a semantic room type, so layouts can be controlled by room counts.
  • A human-in-the-loop framework that lets users refine generated layouts while the constraints stay satisfied.
  • ~90% exact room-count accuracy, 100% ±1 count accuracy and 100% presence precision/recall on the evaluation benchmarks.
  • Spatial topology emerges from count supervision alone, with no topological annotations.

VR CAD Modelling

Virtual Reality Based CAD Modelling Tool

2026 · Under review

HCIVR

An immersive CAD system built in Unity for the HTC Vive, where 3D models are created through natural spatial interaction instead of mouse and keyboard.

  • Precision editing: mesh creation, extrusion, Boolean operations, spline-based modelling, object manipulation and custom gizmos.
  • OBJ import/export, custom mesh generation, a SteamVR interaction pipeline and an undo/redo command architecture.
  • User studies show VR clearly improves modelling efficiency for novices, while highly complex CAD tasks remain hard to scale.

VR Path Planning

Using VR in Path-Planning Algorithm Design

VR

A VR framework for visualising and evaluating 3D autonomous drone navigation in complex environments, used as a tool for analysing the algorithms themselves.

  • A modified A* with turn penalties that removes staircasing while keeping paths near-optimal.
  • 32.25% fewer turning manoeuvres than standard A*, and 27.58% fewer than Dijkstra.
